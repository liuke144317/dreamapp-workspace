# dreamappserver
使用的node版本是12.3.0
# 发布到服务器的经验
1、内网穿透必须使用https，否则无法穿透（浮居）  
2、因为是https，所以必须要有https证书否则无法穿透（比如我有浮居的证书，我可以用浮居的域名，但是natfrp无法使用，会没有反应）  
# 前端打包到ios的经验
1、必须要有开发者证书，可以上淘宝买  
2、服务器和项目都要部署https域名的证书，否则会报出“此服务器的证书无效。您可能正在连接到一个伪装成“192.168.2.104”的服务器，这会威胁到您的机密信息的安全”，我之前卡在这是因为使
用浮居自带的证书，后面改用阿里云自己的域名解析到了浮居的域名，然后下载部署了群晖用的证书，和koa项目用的证书才解决走通的（还有个原因可能是koa的证书部署出错了，部署引用了两个pem文
件，不知道服务器和项目要不要相同的证书，不想再尝试了）  
3、ios中，文件name相同的，ios只会上传一张，多张图要有多个name，在服务器就要做到能接收到多个name的多个文件
# minio使用的经验
1、使用穿透必须代理9000端口才能通过链接访问其中图片  
2、好像请求也不能通过穿透使用，所以开发时本地部署，服务器上的话minio和服务在同一个内网下，所以没有穿透问题
